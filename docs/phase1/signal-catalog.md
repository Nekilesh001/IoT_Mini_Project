# Phase 1 — Dynamic Signal Catalog

Each of the 12 machines features a governed machine-specific signal catalog.

## Machine Signal Catalogs

### 1. CNC-001 (CNC Machining Center)
- `spindle_speed_rpm` (RPM)
- `spindle_load_pct` (%)
- `spindle_temperature_c` (°C)
- `vibration_rms_mm_s` (mm/s)
- `feed_rate_mm_min` (mm/min)
- `coolant_pressure_bar` (bar)
- `tool_wear_pct` (%)
- `axis_x_position_mm`, `axis_y_position_mm`, `axis_z_position_mm` (mm)
- `cycle_state` (ENUM)
- `parts_produced_count` (COUNT)

### 2. CNC-002 (CNC Lathe)
- `spindle_speed_rpm` (RPM)
- `spindle_load_pct` (%)
- `spindle_temperature_c` (°C)
- `vibration_rms_mm_s` (mm/s)
- `feed_rate_mm_min` (mm/min)
- `chuck_pressure_bar` (bar)
- `cutting_temperature_c` (°C)
- `tool_wear_pct` (%)
- `cycle_time_s` (s)
- `parts_produced_count` (COUNT)

### 3. ROB-001 (6-Axis Industrial Robot)
- `joint_1_temp_c` .. `joint_6_temp_c` (°C)
- `joint_1_torque_nm` .. `joint_6_torque_nm` (Nm)
- `position_error_norm_mm` (mm)
- `controller_temperature_c` (°C)
- `cycle_state` (ENUM)
- `operating_hours` (h)
- `alarm_code` (CODE)

### 4. ROB-002 (Welding Robot)
- `joint_1_temp_c`, `joint_2_temp_c` (°C)
- `position_error_norm_mm` (mm)
- `weld_current_a` (A)
- `weld_voltage_v` (V)
- `weld_duration_s` (s)
- `shield_gas_flow_l_min` (L/min)
- `weld_cycles_completed` (COUNT)
- `controller_temperature_c` (°C)

### 5. CON-001 (Industrial Conveyor)
- `belt_speed_m_s` (m/s)
- `drive_motor_current_a` (A)
- `drive_motor_temp_c` (°C)
- `vibration_amplitude_mm` (mm)
- `belt_tension_n` (N)
- `load_kg` (kg)
- `throughput_units_min` (units/min)
- `jam_state` (BOOL)
- `start_stop_cycles` (COUNT)

### 6. PRS-001 (Industrial Press)
- `ram_position_mm` (mm)
- `ram_speed_mm_s` (mm/s)
- `press_force_kn` (kN)
- `hydraulic_pressure_bar` (bar)
- `oil_temperature_c` (°C)
- `motor_load_pct` (%)
- `stroke_count` (COUNT)
- `tool_usage_pct` (%)
- `alarm_state` (BOOL)

### 7. IMM-001 (Injection Molding Machine)
- `barrel_temp_zone_1_c` .. `zone_4_c` (°C)
- `mold_temperature_c` (°C)
- `injection_pressure_bar` (bar)
- `holding_pressure_bar` (bar)
- `screw_position_mm` (mm)
- `screw_speed_rpm` (RPM)
- `injection_time_s` (s)
- `cooling_time_s` (s)
- `cycle_time_s` (s)
- `shot_count` (COUNT)
- `alarm_state` (BOOL)

### 8. CMP-001 (Air Compressor)
- `discharge_pressure_bar` (bar)
- `regulating_pressure_bar` (bar)
- `element_temperature_c` (°C)
- `ambient_temperature_c` (°C)
- `motor_current_a` (A)
- `motor_load_pct` (%)
- `running_hours` (h)
- `starts_count` (COUNT)
- `energy_kwh` (kWh)
- `alarm_state` (BOOL)

### 9. PMP-001 (Industrial Pump)
- `suction_pressure_bar` (bar)
- `discharge_pressure_bar` (bar)
- `flow_rate_m3_h` (m³/h)
- `speed_rpm` (RPM)
- `motor_current_a` (A)
- `power_kw` (kW)
- `bearing_temperature_c` (°C)
- `vibration_x_mm_s`, `vibration_y_mm_s` (mm/s)
- `start_stop_count` (COUNT)
- `alarm_state` (BOOL)

### 10. VIS-001 (Vision Inspection Station)
- `station_state` (ENUM)
- `camera_state` (ENUM)
- `inspection_cycle_time_ms` (ms)

- `good_parts_count` (COUNT)
- `defect_parts_count` (COUNT)
- `defect_rate_pct` (%)
- `confidence_score_pct` (%)
- `lighting_level_lux` (lux)
- `camera_temperature_c` (°C)

### 11. AGV-001 (Autonomous Mobile Robot)
- `pos_x_m`, `pos_y_m` (m)

- `motor_speed_rpm` (RPM)
- `motor_current_a` (A)
- `active_job_id` (STRING)
- `total_distance_m` (m)
- `docking_state` (ENUM)
- `obstacle_state` (ENUM)
- `safety_state` (ENUM)

### 12. CHL-001 (Industrial Chiller)
- `supply_temperature_c`, `return_temperature_c` (°C)
- `flow_rate_l_min` (L/min)
- `compressor_state` (ENUM)
- `compressor_current_a` (A)
- `compressor_load_pct` (%)
- `high_side_pressure_bar`, `low_side_pressure_bar` (bar)
- `ambient_temperature_c` (°C)
- `energy_kwh` (kWh)
- `running_hours` (h)
- `alarm_state` (BOOL)
